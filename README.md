# Projektant Modów

**Projektant Modów** to narzędzie do planowania i organizowania projektów modów do Minecrafta.

Pomaga uporządkować pomysł na moda, jego mechaniki, elementy, obszary projektu, zadania i zależności między systemami.

## ✨ Funkcje

- 🧠 Planowanie pomysłu na mod
- ⚙️ Tworzenie i organizowanie mechanik
- 📦 Dodawanie elementów moda, np. przedmiotów, bloków, mobów, dźwięków czy tekstur
- 🗺️ Wizualna mapa projektu z obszarami i zależnościami
- ✅ Zadania przypisane do mechanik i elementów
- 💾 Automatyczne zapisywanie projektu w przeglądarce
- 📤 Eksport projektu do `.modplan.json`
- 📥 Import wcześniej zapisanych projektów
- 📋 Historia aktywności
- 🇵🇱 Interfejs w języku polskim

## 🚀 Używanie

Możesz korzystać z Projektanta bez instalowania dodatkowych programów.

**[Otwórz Projektanta Modów](https://hawe-xd.github.io/PM-hawe_xd/)**

Wszystkie projekty są przechowywane lokalnie w przeglądarce. Do przenoszenia projektu między urządzeniami użyj funkcji eksportu i importu `.modplan.json`.

## 🎮 Dla kogo?

Projektant jest przeznaczony dla osób tworzących mody do Minecrafta, które chcą najpierw uporządkować pomysł i zaplanować jego wykonanie.

Nie jest wymagany konkretny mod loader ani program do tworzenia modów — narzędzie służy do **planowania projektu**, a nie do bezpośredniego tworzenia pliku `.jar`.

## 🛠️ Technologia

Projektant jest aplikacją webową działającą po stronie przeglądarki.

- HTML
- CSS
- JavaScript
- GitHub Pages

## 📄 Format projektu

Projekty można eksportować jako pliki:

`.modplan.json`

Dzięki temu można wykonać kopię zapasową projektu lub przenieść go na inne urządzenie.
